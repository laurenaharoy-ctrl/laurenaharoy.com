Welche Daten werden erhoben?

Diese Website enthält kein Kontaktformular, das Daten erhebt. Verarbeitet werden ausschließlich die personenbezogenen Daten, die Sie mir bei der Terminvereinbarung per Telefon oder E-Mail mitteilen (Name, Telefonnummer, E-Mail-Adresse, Angaben zu Ihrem Tier), sowie die Angaben auf Ihrer Überweisung oder Wero-Zahlung.

  • Besuch der Website: Diese Website wird bei GitHub Pages (GitHub, Inc.) gehostet. GitHub kann aus Sicherheitsgründen technische Verbindungsdaten (IP-Adresse) speichern. Die Website setzt keine Werbe- oder Statistik-Cookies.
  • Spracheinstellung: Wenn Sie eine Sprache wählen, wird diese Wahl in Ihrem Browser gespeichert (lokaler Speicher), damit die Website beim nächsten Besuch in dieser Sprache angezeigt wird. Diese Information wird nicht an mich übermittelt.

Wozu werden diese Daten erhoben?

Ausschließlich, um Ihren Termin für die Verhaltensberatung zu organisieren und durchzuführen, sowie für die Nachbetreuung und die Rechnungsstellung.

Wie lange werden diese Daten gespeichert?

Die Termindaten werden so lange aufbewahrt, wie es für die Kundenbeziehung nötig ist, und danach gemäß den gesetzlichen Aufbewahrungspflichten (insbesondere buchhalterischen) gelöscht oder archiviert.
